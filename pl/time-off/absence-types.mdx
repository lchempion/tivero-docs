## Typy systemowe

Każda przestrzeń ma od razu zestaw typów systemowych.

| Typ | Kategoria | Odejmuje z salda | Uwagi |
|---|---|---|---|
| Urlop wypoczynkowy | Pracownicza (UoP) | tak |  |
| Urlop na żądanie | Pracownicza (UoP) | tak |  |
| Opieka nad dzieckiem (art. 188 KP) | Pracownicza (UoP) | tak |  |
| Siła wyższa | Pracownicza (UoP) | tak |  |
| Urlop opiekuńczy | Pracownicza (UoP) | tak |  |
| Urlop okolicznościowy | Pracownicza (UoP) | tak |  |
| Urlop bezpłatny | Pracownicza (UoP) | nie |  |
| Zwolnienie lekarskie (L4) | Pracownicza (UoP) | nie | Typ prywatny. Domyślnie nie wymaga akceptacji. |
| Planowana niedostępność | B2B | tak, gdy zasada określa limit |  |
| Przerwa w świadczeniu usług | B2B | tak, gdy zasada określa limit |  |
| Niedyspozycyjność | B2B | tak, gdy zasada określa limit |  |
| Niepłatna niedostępność | B2B | nie |  |

Kolumny na liście **Typy nieobecności** pokazują dla każdego typu jednostkę, czy **Odejmuje z salda**, czy **Wymaga akceptacji** i jego widoczność.

W typie systemowym możesz zmienić tylko nazwę, prywatność i aktywność. Kategoria, jednostka i wpływ na saldo są stałe.

<Note>
  Zwolnienie lekarskie (L4) rejestrujesz w Tivero jako nieobecność. Tivero nie przyjmuje dokumentów L4 — nie dołączaj do wniosku dokumentów ani szczegółów medycznych.
</Note>

## Dodaj własny typ

Własne typy są dostępne w planach, które je obejmują. Zobacz [Plany i okres próbny](/pl/billing/plans-and-trial).

<Steps>
  <Step title="Otwórz formularz">
    Kliknij **Dodaj typ**.
  </Step>
  <Step title="Opisz typ">
    Wpisz **Nazwę** i wybierz **Kategorię** (Pracownicza (UoP), B2B albo Inna) oraz **Jednostkę** (Dni albo Godziny).
  </Step>
  <Step title="Ustaw zachowanie">
    Włącz lub wyłącz **Odejmuje z salda**, **Wymaga akceptacji**, **Szczegóły widoczne dla wszystkich** i **Aktywny**.
  </Step>
  <Step title="Zapisz">
    Kliknij **Dodaj typ**.
  </Step>
</Steps>

Nowy typ jest dostępny dla osób dopiero wtedy, gdy obejmuje go ich [zasada nieobecności](/pl/time-off/absence-policies).

## Prywatność szczegółów

Gdy **Szczegóły widoczne dla wszystkich** są wyłączone, typ jest prywatny. Szczegóły widzą tylko pracownik, jego przełożony i dział kadr (HR). Pozostali widzą w kalendarzu tylko słowo „Nieobecność”.

## Wyłącz typ

Wyłącz przełącznik **Aktywny**, jeśli typ nie powinien być dostępny w nowych wnioskach. Istniejące wnioski pozostają bez zmian.
