Każda osoba z dostępem do Tivero ma jedną rolę w danej przestrzeni. Rola decyduje, co osoba widzi w menu i jakie działania może wykonać.

## Role

| Rola | Dla kogo | W skrócie |
|---|---|---|
| **Pracownik** | Każda osoba w organizacji | Składa wnioski, widzi własne salda i kalendarz. |
| **Manager** | Przełożeni zespołów | Akceptuje wnioski i widzi nieobecności swojego zespołu. |
| **Kadry (HR)** | Dział kadr | Zarządza osobami, zasadami, limitami i typami nieobecności. |
| **Administrator** | Osoby zarządzające Tivero | Zarządza ustawieniami przestrzeni, osobami, zasadami, integracjami i planem. |
| **Właściciel** | Osoba, która utworzyła przestrzeń (lub przejęła własność) | Pełny dostęp, w tym przekazanie własności i usunięcie organizacji. |

## Co widzi każda rola

| Sekcja | Pracownik | Manager | Kadry (HR) | Administrator | Właściciel |
|---|---|---|---|---|---|
| Pulpit, Kalendarz, Wnioski, Ustawienia | ✓ | ✓ | ✓ | ✓ | ✓ |
| Osoby, Zespoły, Raporty | — | tylko swój zespół, do odczytu | ✓ | ✓ | ✓ |
| Zasady nieobecności, Typy nieobecności | — | — | ✓ | ✓ | ✓ |
| Integracje | — | — | — | ✓ | ✓ |
| Plan i płatności | — | — | — | ✓ | ✓ |

## Najważniejsze uprawnienia

| Działanie | Pracownik | Manager | Kadry (HR) | Administrator | Właściciel |
|---|---|---|---|---|---|
| Składanie własnych wniosków | ✓ | ✓ | ✓ | ✓ | ✓ |
| Akceptowanie wniosków | gdy jest wskazaną osobą zatwierdzającą | gdy jest wskazaną osobą zatwierdzającą (zwykle dla swojego zespołu) | gdy jest wskazaną osobą zatwierdzającą | ✓ | ✓ |
| Przekazywanie akceptacji innej osobie | — | — | ✓ | ✓ | ✓ |
| Dodawanie osób, import, salda | — | — | ✓ | ✓ | ✓ |
| Zasady, typy nieobecności, grafiki, dni firmowe | — | — | ✓ | ✓ | ✓ |
| Eksport danych | — | — | ✓ | ✓ | ✓ |
| Zespoły (tworzenie i edycja) | — | — | — | ✓ | ✓ |
| Zmiana roli członka | — | — | — | ✓ | ✓ |
| Integracje, ustawienia organizacji, plan | — | — | — | ✓ | ✓ |
| Przekazanie własności, usunięcie organizacji | — | — | — | — | ✓ |

<Note>
  Wniosek rozpatruje osoba zatwierdzająca przypisana do bieżącego etapu, niezależnie od roli, a także Administrator i Właściciel. Nikt nie akceptuje własnego wniosku. Szczegóły: [Jak działa akceptacja](/pl/time-off/approval-process).
</Note>

## Zmiana roli osoby

**Kto:** Administrator lub Właściciel.

<Steps>
  <Step title="Otwórz osobę">
    Przejdź do **Osoby** i otwórz edycję osoby.
  </Step>
  <Step title="Wybierz rolę dostępu">
    Zmień rolę dostępu i zapisz. Jeśli osoba nie przyjęła jeszcze zaproszenia, rola zostanie nadana po jego przyjęciu.
  </Step>
</Steps>

Zakładka **Ustawienia → Członkowie i role** pokazuje, ile osób ma każdą rolę, i opis ról.

<Warning>
  Roli Właściciela nie nadaje się w oknie osoby. Właściciel może **przekazać własność** innemu aktywnemu członkowi w **Ustawienia → Członkowie i role**. Po przekazaniu dotychczasowy właściciel staje się Administratorem. Aby potwierdzić, wpisujesz adres e-mail nowego właściciela. Tej operacji nie cofniesz samodzielnie.
</Warning>
