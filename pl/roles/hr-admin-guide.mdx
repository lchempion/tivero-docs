Ten przewodnik jest dla osób, które konfigurują Tivero i zarządzają nim w organizacji. Szczegółowe instrukcje są w artykułach, do których prowadzą linki.

## Kto co może

| Obszar | Kadry (HR) | Administrator | Właściciel |
|---|---|---|---|
| Osoby, import, salda | ✓ | ✓ | ✓ |
| Typy i zasady nieobecności | ✓ | ✓ | ✓ |
| Grafiki pracy, dni firmowe, kalendarz świąt | ✓ | ✓ | ✓ |
| Przekazywanie akceptacji, delegowanie w imieniu innych | ✓ | ✓ | ✓ |
| Raporty i eksport danych | ✓ | ✓ | ✓ |
| Akceptowanie dowolnych wniosków | tylko gdy jest wskazaną osobą zatwierdzającą | ✓ | ✓ |
| Zespoły, zmiana roli członka, integracje, ustawienia organizacji, plan i płatności | — | ✓ | ✓ |
| Przekazanie własności, usunięcie organizacji | — | — | ✓ |

Pełna tabela: [Role i uprawnienia](/pl/roles/roles-and-permissions).

## Pierwsza konfiguracja

Przejdź przez [Szybki start dla administratora](/pl/getting-started/admin-quick-start). Najważniejsze kroki:

<Steps>
  <Step title="Potwierdź kalendarz świąt">
    Bez potwierdzonego kalendarza pracownicy nie złożą wniosków liczonych w dniach roboczych. Zobacz [Kalendarz świąt](/pl/calendars/holiday-calendar).
  </Step>
  <Step title="Przygotuj zasady nieobecności">
    Zasada określa typy, wymiar i akceptację. Zobacz [Zasady nieobecności](/pl/time-off/absence-policies).

    <Frame>
      <img src="/images/pl/policy-rules.webp" alt="Szczegóły zasady UoP — 26 dni: karty Zasady, Akceptacja i Przypisania oraz pula Urlop wypoczynkowy 26 dni wspólna dla urlopu wypoczynkowego i na żądanie" />
    </Frame>
  </Step>
  <Step title="Dodaj osoby i zespoły">
    [Dodaj osoby](/pl/people/add-and-invite-people), [zaimportuj je z pliku](/pl/people/import-people) albo [zsynchronizuj z Microsoft 365](/pl/microsoft-365/directory-sync). Następnie [utwórz zespoły](/pl/people/teams-and-supervisors).
  </Step>
  <Step title="Ustaw salda i sprawdź akceptacje">
    [Ustaw salda początkowe](/pl/time-off/balances) i upewnij się, że każdy ma [osobę zatwierdzającą](/pl/time-off/approval-process).
  </Step>
</Steps>

## Gdzie znaleźć najczęstsze sprawy

| Chcesz… | Przejdź do |
|---|---|
| dodać lub zaprosić osobę | **Osoby** → **Dodaj osobę** · [Dodawanie i zapraszanie osób](/pl/people/add-and-invite-people) |
| zaimportować listę osób | **Osoby** → **Importuj** · [Import osób z pliku](/pl/people/import-people) |
| ustawić zespół i managera | **Zespoły** · [Zespoły i przełożeni](/pl/people/teams-and-supervisors) |
| dodać własny typ nieobecności | **Typy nieobecności** · [Typy nieobecności](/pl/time-off/absence-types) |
| zmienić wymiar lub akceptację w zasadzie | **Zasady nieobecności** · [Zasady nieobecności](/pl/time-off/absence-policies) |
| poprawić saldo osoby | strona osoby → **Saldo** · [Salda](/pl/time-off/balances) |
| sprawdzić, kto zatwierdzi wniosek | **Ustawienia → Procesy akceptacji** · [Jak działa akceptacja](/pl/time-off/approval-process) |
| przekazać oczekujący wniosek | wniosek → **Przekaż do innej osoby** · [Akceptowanie wniosków](/pl/time-off/approve-requests) |
| ustawić tydzień pracy lub dni firmowe | **Ustawienia → Dni pracy i święta** · [Grafiki pracy](/pl/calendars/work-schedules), [Dni firmowe](/pl/calendars/company-days) |
| przygotować dane dla księgowości | **Ustawienia → Eksport danych** · [Eksport danych](/pl/reports/exports) |
| sprawdzić obłożenie zespołów | **Raporty** · [Raporty](/pl/reports/reports) |
| połączyć Microsoft 365 (Administrator) | **Integracje** · [Przewodnik administratora Microsoft 365](/pl/roles/microsoft-365-admin-guide) |
| zarządzać planem (Administrator) | **Ustawienia → Plan i płatności** · [Plany i okres próbny](/pl/billing/plans-and-trial) |
