This guide is for the people who set up and run Tivero in the organization. Detailed instructions are in the linked articles.

## Who can do what

| Area | HR | Administrator | Owner |
|---|---|---|---|
| People, import, balances | ✓ | ✓ | ✓ |
| Absence types and policies | ✓ | ✓ | ✓ |
| Work schedules, company days, holiday calendar | ✓ | ✓ | ✓ |
| Reassigning approvals, delegating on someone's behalf | ✓ | ✓ | ✓ |
| Reports and data export | ✓ | ✓ | ✓ |
| Approving any request | only when named as the approver | ✓ | ✓ |
| Teams, changing a member's role, integrations, organization settings, plan and billing | — | ✓ | ✓ |
| Transferring ownership, deleting the organization | — | — | ✓ |

Full table: [Roles and permissions](/en/roles/roles-and-permissions).

## First setup

Follow the [Admin quick start](/en/getting-started/admin-quick-start). The key steps:

<Steps>
  <Step title="Confirm the holiday calendar">
    Until the calendar is confirmed, employees can't submit requests counted in working days. See [Holiday calendar](/en/calendars/holiday-calendar).
  </Step>
  <Step title="Prepare absence policies">
    A policy sets the types, the allowance and approval. See [Absence policies](/en/time-off/absence-policies).

    <Frame>
      <img src="/images/en/policy-rules.webp" alt="Policy details: the Rules, Approval and Assignments tabs and a Vacation leave pool of 26 days shared by vacation and on-demand leave" />
    </Frame>
  </Step>
  <Step title="Add people and teams">
    [Add people](/en/people/add-and-invite-people), [import them from a file](/en/people/import-people) or [sync them from Microsoft 365](/en/microsoft-365/directory-sync). Then [create teams](/en/people/teams-and-supervisors).
  </Step>
  <Step title="Set balances and check approvals">
    [Set opening balances](/en/time-off/balances) and make sure everyone has an [approver](/en/time-off/approval-process).
  </Step>
</Steps>

## Where to find common tasks

| You want to… | Go to |
|---|---|
| add or invite a person | **People** → **Add person** · [Add and invite people](/en/people/add-and-invite-people) |
| import a list of people | **People** → **Import** · [Import people from a file](/en/people/import-people) |
| set a team and its manager | **Teams** · [Teams and supervisors](/en/people/teams-and-supervisors) |
| add a custom absence type | **Absence types** · [Absence types](/en/time-off/absence-types) |
| change a policy's allowance or approval | **Absence policies** · [Absence policies](/en/time-off/absence-policies) |
| correct a person's balance | person page → **Balance** · [Balances](/en/time-off/balances) |
| check who approves a request | **Settings → Approval processes** · [How approval works](/en/time-off/approval-process) |
| reassign a pending request | request → **Reassign to someone else** · [Approve requests](/en/time-off/approve-requests) |
| set the work week or company days | **Settings → Working days and holidays** · [Work schedules](/en/calendars/work-schedules), [Company days](/en/calendars/company-days) |
| prepare data for accounting | **Settings → Data export** · [Data export](/en/reports/exports) |
| check team coverage | **Reports** · [Reports](/en/reports/reports) |
| connect Microsoft 365 (Administrator) | **Integrations** · [Microsoft 365 admin guide](/en/roles/microsoft-365-admin-guide) |
| manage the plan (Administrator) | **Settings → Plan and billing** · [Plans and trial](/en/billing/plans-and-trial) |
